说明与限制
  • 容器 xiaomi-plugin-jellyfin 仅挂载配置、缓存与所选媒体目录，不挂载 Docker socket，不使用 privileged 或 host 网络。
  • 数据持久化：/config（用户/库配置）、/cache（缓存，可丢弃）、/media（媒体文件）。
  • 端口映射：宿主机 8097→8096（HTTP）、8920→8920（HTTPS）、7359/UDP（DLNA）。
  • Jellyfin 为开源软件，本插件不代表官方背书。
  • 停止或卸载插件只停止容器，配置与媒体文件都会保留。
  • 首次使用：用浏览器打开入口地址完成向导，创建管理员并添加媒体库（选择 /media 下的子目录）。向导完成前同网段设备可能抢先初始化，请尽快设置。

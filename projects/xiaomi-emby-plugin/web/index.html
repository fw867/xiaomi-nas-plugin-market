这两个目录会怎么被使用

媒体目录在容器内以读写方式挂载为 /mnt/media：Emby 会把元数据、字幕等写回该目录，也会以该目录属主身份修改其中的文件；添加媒体库时请选择其下的子目录。

配置目录挂载为 /config，存放 Emby 的数据库、缓存、插件与日志（当前约十几 MB）。留空时它保存在插件私有目录里、外部看不到；指定一个存储目录后就能在文件管理器里直接查看、备份或迁移。指定时插件不会改动该目录现有文件的属主，建议选一个空目录，或已有的 Emby 配置目录。

说明与限制
  • 容器 xiaomi-plugin-emby 仅挂载插件私有配置目录与所选媒体目录，不挂载 Docker socket，不使用 privileged 或 host 网络。
  • 所选媒体目录为读写挂载，Emby 可在其中新增、修改和删除文件（用于元数据与字幕），请确认该目录已有备份。
  • 本机没有可供 Emby 使用的硬件转码单元（GPU 是 Mali Valhall-JM，视频编解码由 Realtek VPU 提供、走 V4L2 M2M 接口，Emby 不支持），因此只能由客户端直接解码播放；转码会落到 CPU，较慢。
  • 服务端口 8096 对整个局域网开放，Emby 客户端直接连接该端口。
  • 停止或卸载插件只停止容器，Emby 配置与媒体文件都会保留。

说明与限制

  • 容器 xiaomi-plugin-emby 仅挂载插件私有配置目录与所选媒体目录，不挂载 Docker socket，不使用 privileged 或 host 网络。
  • 所选媒体目录为读写挂载，Emby 可在其中新增、修改和删除文件（用于元数据与字幕），请确认该目录已有备份。
  • 未映射 /dev/dri，不启用硬件转码；转码由 CPU 完成，可能较慢。
  • 服务端口 8096 对整个局域网开放，Emby 客户端直接连接该端口。
  • 停止或卸载插件只停止容器，Emby 配置与媒体文件都会保留。

# 内网穿透（fwclient）

小米智能存储社区插件：管理 **fwclient** 内网穿透客户端。

**不是 fwserver / fwclient 官方产品。** 随包分发 `fwclient-linux-arm64`。

## 功能

- 配置 **服务器域名**、**访问令牌**（可选跳过 TLS）
- 优先后台守护运行：`fwclient -s <域名> -t <令牌> -d`；新版客户端再带上 `-dir <数据目录>/run`
- 显示当前客户端版本（`-v`）
- **检查升级**（`-u`）
- 启停服务；停止时先本地探测是否支持规范关闭 `-k`，支持则优先用 `fwclient -k`，否则回退到信号终止（`SIGTERM` → `SIGKILL`）
- 日志摘要按「`-dir` 目录 → `/var/log/fwclient` → 二进制同目录」依次找候选文件，都找不到时给出明确提示

## 使用

1. 在网关管理端创建访问令牌（`tk_…`）
2. 打开本插件，填写服务器域名与令牌后「保存并启动」
3. 到管理端「内网穿透」配置穿透规则
4. 需要升级时点「检查升级」

## 运行数据与日志路径

新版 fwclient 默认不再把 pid / 日志 / 设备标识放在二进制同目录，而是遵循 Linux 规范路径，
四个参数都可以覆盖（`-dir` 优先级最高）：

| 参数 | 含义 | 上游默认值 |
| --- | --- | --- |
| `-dir string` | 运行数据目录：pid / 日志 / 设备标识都放这一处 | 无（未传时按下表各自的默认值） |
| `-l string` | 日志文件路径 | `/var/log/fwclient/fwclient.log` |
| `-pidfile string` | pid 文件路径 | `/run/fwclient/fwclient.pid` |
| `-idfile string` | 设备标识路径 | 二进制同目录 `fwclient.id` |

插件策略：**启动前用缓存的 `fwclient -h` 探测**，只有帮助里确实有 `-dir` 时才加
`-dir <数据目录>/run`（目录由插件创建，权限 0700，与数据目录一致），让 pid / 日志 / 设备标识
自包含在插件自己的数据目录里，不依赖 `/var/log` 与 `/run`；老版本不认这个参数（可能直接报错退出），
探测不到就**完全按旧方式启动**，一个新增参数都不加。

> 兼容老版本：进程发现一直是扫 `/proc` 命令行（不读 pidfile），所以新旧版本都能找到进程。

运行日志按下面顺序取**第一个存在的**候选文件：

1. `<数据目录>/run/fwclient.log`（插件用 `-dir` 指定的位置，日志文件名沿用 `-l` 的默认名）
2. `/var/log/fwclient/fwclient.log`（新版默认位置）
3. `<数据目录>/fwclient.log`（旧位置，二进制同目录，兼容老版本）

候选文件不存在、为空或刚好在轮转（读取失败）都不会报错：不存在或读不到就换下一个候选，
全部都没有时页面显示「未找到运行日志：fwclient 可能未运行，或日志路径与预期不同」；
第一个存在的候选文件为空时按「暂无日志」处理。

## 停止服务

点「停止服务」时先做一次**本地能力探测**：执行 `fwclient -h`，在帮助输出里找 `-k`
（只跑本地帮助，不联网、不触发版本检查或自动升级），然后：

- **探测到支持 `-k`**：执行规范关闭命令 `fwclient -k`（与启动相同的二进制、数据目录与运行身份），
  最多轮询约 3 秒等待退出；确认**没有任何 fwclient 进程残留**才算成功，成功即返回，不再发任何信号。
- **明确不支持 `-k`**（帮助里没有该选项）：直接走信号终止，不执行 `-k`——老版本二进制遇到未知参数
  可能不报错、反而再拉起一个实例，留下重复隧道。这属于预期路径，只写日志，不占用页面提示条。
- **探测结果不确定**（`-h` 执行失败或没有输出）：退化成先试一次 `-k`。

只要**真的尝试过** `-k` 却未生效（退出码非 0、执行异常、找不到二进制，或等待超时后仍有进程），
原因都会写入日志与页面提示，然后对**所有残留的 fwclient 进程**走信号终止
`SIGTERM` → 轮询 → `SIGKILL`，保证一定停得掉，也不会留下重复实例。

> 版本差异：随包的 `fwclient-linux-arm64` 是老版本，帮助里没有 `-k`（它启动时会自动检测并升级重启），
> 所以停止时以探测结果为准——老版本直接信号终止，升级到支持 `-k` 的版本后即走规范关闭。

## 数据目录

| 文件 | 说明 |
| --- | --- |
| `fwclient` | 可执行文件（初始化时从包内拷入，升级会替换） |
| `settings.json` | 服务器/令牌（0600，不回显明文令牌） |
| `run/` | 新版客户端的运行数据目录（`-dir`，0700）：`fwclient.log` / `fwclient.pid` / `fwclient.id` |
| `fwclient.id` | 设备唯一标识（老版本位置） |
| `fwclient.log` | 运行日志（老版本位置） |

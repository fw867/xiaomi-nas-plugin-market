这个插件会做什么

配置目录挂载为容器内 /dpanel，存放面板数据库、证书与日志。留空时使用插件私有目录；指定存储目录后便于备份与迁移。

权限说明：DPanel 是 Docker 管理面板，容器必须挂载宿主机的 /var/run/docker.sock 才能管理容器、镜像与 Compose。这意味着面板内的操作拥有 Docker 级权限，请仅在受信任的局域网中使用，并在首次打开面板后立即设置管理员账号。

面板 Web 端口固定映射为 8807（Lite 版，不占用 80/443）。

说明与限制
  • 容器 xiaomi-plugin-dpanel 只挂载 Docker socket 与所选/私有配置目录，不使用 privileged 或 host 网络。
  • 插件页只负责启停本容器，不代理 DPanel 的 Docker 操作接口。
  • DPanel 与 DPanel 开发团队为第三方软件，本插件不代表官方背书。
  • 停止或卸载插件只停止容器，配置与容器管理数据保留。

「打开控制台」在插件内直接管理任务（同源 API，不依赖第三方页面）。局域网也可打开上面的 9091 地址使用官方 WebUI。

说明与限制
  • 容器 xiaomi-plugin-transmission 只挂载所选的配置、下载、监控目录，不挂载 Docker socket，不使用 privileged 或 host 网络。
  • WebUI 端口 9091（TCP）对局域网开放；BT 入站端口 51413（TCP/UDP）已映射，公网入站仍需在路由器转发。
  • 「打开控制台」为插件内置界面，通过 Transmission JSON-RPC 拉取任务；卡片里的 9091 地址是官方 WebUI 直连入口。
  • 停止或卸载插件只停止容器，配置与已下载文件都会保留。
